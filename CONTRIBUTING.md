# Contributing

This repository is primarily a research artifact supporting a scientific publication.

## Reproducibility-first contributions

Please keep contributions focused on:

- reproducibility,
- correctness,
- documentation,
- experimental transparency,
- bug fixes,
- and clearly identified methodological improvements.

When proposing a change that affects reported results, include:

1. the exact command used;
2. software/hardware environment;
3. random seeds;
4. before/after metrics;
5. whether the change affects the manuscript's reported experiments.

Do not commit the CIC-IDS2017 dataset or large generated intermediate arrays.

## Pull requests

Please describe:

- what changed;
- why it changed;
- how it was tested;
- whether any reported result changes;
- and any limitations or known reproducibility differences.
