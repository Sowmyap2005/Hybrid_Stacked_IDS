# Security

This repository contains research code for network intrusion detection.

## Reporting a security issue

If you discover a security issue in the repository infrastructure, CI configuration, or accidentally committed credential, please report it privately to the repository maintainers rather than opening a public issue.

Do not submit passwords, API keys, tokens, private network data, or other sensitive information in issues or pull requests.

The machine-learning models in this repository are research artifacts and should not be assumed to provide complete protection against real-world cyber threats.
